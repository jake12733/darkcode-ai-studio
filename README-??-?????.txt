================================================================
DARK CODE AI (다크코드) - 집 컴퓨터 연동 및 실행 가이드
================================================================

사용자님께서 지금까지 업그레이드하신 모든 최신 기능:
- 100% 한국인 실사 AI 사진 생성기 (외국인 스톡 원천 차단)
- 초고속 터보 수정 엔진 (수정 딜레이 90초 -> 6초 단축)
- Awwwards/Apple급 모션 효과 (스크롤 인뷰 60fps 페이드업, 3D 틸트)
- 실사 동영상 자동 탑재 (<video> 앰비언트 비디오)
- 실제 동작하는 3단계 인터랙티브 스마트 예약 시스템 & 실시간 견적 계산기
- 엑스박스(깨진 이미지) 원천 방지 및 실시간 자가 치유
- 무중단 평생 무료 풀 폴백 엔진

이 모든 것이 포함된 완성형 패키지입니다.
집 컴퓨터(집컴)에서 사용하시는 방법은 아래 2가지 중 편한 것을 고르시면 됩니다.

----------------------------------------------------------------
[방법 1] 설치 없이 3초 만에 집컴에서 열기 (가장 편리한 방법)
----------------------------------------------------------------
이미 깃허브 서버에 모든 최신 파일이 실시간 배포되어 있으므로,
집컴의 웹 브라우저(Chrome 또는 Edge)에서 아래 주소만 열어주시면 끝납니다.

👉 주소: https://jake12733.github.io/darkcode-ai/?v=20261124turbo1

★ 팁: 이 주소를 집컴 브라우저 즐겨찾기(북마크)에 등록해 두시면,
USB로 파일을 옮길 필요도 없이 집컴, 노트북, 태블릿 어디서나
100% 동일한 최신 버전으로 즉시 작업하실 수 있습니다.


----------------------------------------------------------------
[방법 2] 집컴에 다운로드하여 로컬 파일로 단독 실행하기
----------------------------------------------------------------
1. 이 압축파일(darkcode-ai-집컴연동패키지.zip)을 USB, 카카오톡 나에게 보내기,
   또는 구글 드라이브를 통해 집 컴퓨터로 옮깁니다.

2. 집 컴퓨터의 원하는 폴더(예: 바탕화면)에 압축을 풉니다.

3. 폴더 안에 있는 [start-darkcode.bat] 파일을 더블클릭합니다.
   - Python이 설치되어 있으면: 로컬 웹 서버(localhost:8080)로 자동 구동됩니다.
   - Python이 없어도: 기본 브라우저로 index.html이 바로 열립니다.


----------------------------------------------------------------
[대화 기록 및 로그인 세션 연동]
----------------------------------------------------------------
- 게스트 모드: 브라우저 내부(localStorage)에 안전하게 저장됩니다.
- 회원가입/로그인 모드: 구글(Google) 원클릭 로그인이나 이메일 로그인을 사용하시면
  회사 컴퓨터에서 하던 작업 세션을 집 컴퓨터에서도 이어받아 사용하실 수 있습니다.
