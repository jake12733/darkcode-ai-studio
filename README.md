# ILL AI · All-in-One Creative & Engineering Workspace

멀티 도메인 AI 오케스트레이션, 무료 클라우드 엔진 자동 로드밸런싱, Pexels 고화질 사진·영상 자동 매칭, 모션그래픽 웹사이트·60fps 영상·인터랙티브 음악 스튜디오, 로컬 실행 검증 콘솔, 동의 기반 원격 지원 콘솔을 하나로 통합한 웹 워크스페이스입니다.

## 주요 구성
- **메인 워크스페이스 (`index.html`)**: 멀티 보드 비주얼 캔버스 · 모션그래픽 웹사이트 제작 · ILL Vision HD 이미지 · ILL Motion 60fps 영상 · ILL Sound 인터랙티브 작곡 · 코드 아키텍처 & 전략 리서치
- **ILL AI STUDIO (`studio.html`)**: AI 작곡, 뮤직비디오 제작, 홍보영상 자동 생성, 라이브러리
- **Live Execution Console (`astra.html`)**: 로컬 실행기 실측 검증 및 원장 관리
- **Remote Control Console (`remote.html` · `consent.html`)**: 동의 기반 WebRTC 원격 지원 콘솔
