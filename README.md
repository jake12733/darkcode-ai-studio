# DARK CODE AI · Clean Multi-Model Workspace

멀티 AI 오케스트레이션, 무료 API 풀 자동 라우팅(WRR), 로컬 Ollama 6-에이전트, AI 음악·영상 스튜디오, 로컬 코드 실측 검증(Astra EXEC), 동의 기반 원격 지원 콘솔을 하나의 깔끔한 워크스페이스에 통합한 정적 웹 앱입니다.

## 주요 구성
- **메인 워크스페이스 (`index.html`)**: 멀티 AI 상의 · 빠른 실행 · Claude Final · CORE 게이트웨이 · 로컬 6-에이전트 · EXEC 모드 + 문서/코드/실시간 미리보기/스냅샷/LIVE 드로어 + 실시간 대시보드
- **DARK CODE STUDIO (`studio.html`)**: AI 작곡, 뮤직비디오 제작, 홍보영상 자동 생성, 라이브러리
- **Astra Live Execution Console (`astra.html`)**: 로컬 러너 실측 검증 및 Committed/Runs 원장
- **Remote Control Console (`remote.html` · `consent.html`)**: 동의 기반 WebRTC 원격 지원 콘솔
